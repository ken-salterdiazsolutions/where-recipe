# Security policy

## Supported versions

Only the latest version on addons.mozilla.org gets security fixes.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Anything older | No |

## Reporting a vulnerability

Email support@salterdiazsolutions.com with "Security" in the subject.

Include:
- What the issue is and what an attacker could do with it
- Steps to reproduce, with a page or recipe that triggers it if relevant
- The extension version, and the browser and version you used

Do not open a public issue or post details elsewhere until a fix is released.

## What to expect

- We acknowledge your report within 5 business days.
- We aim to release a fix within 30 days of confirming an issue, sooner for serious ones.
- We tell you when the fix is out, and credit you in the release notes if you want.

## Scope

In scope:
- Script injection from page content into the recipe card, the tab viewer, the shopping list or settings
- A web page reading or changing the extension's stored data or settings
- A web page getting access to extension pages or extension permissions
- Data stored when it should not be, including from private windows
- Anything that sends data off the device without the user asking

Out of scope:
- Bugs in the websites the extension reads, or in the browser itself
- Recipes shown wrongly because a site publishes incorrect data
- Issues that need physical access to an unlocked device or a compromised browser profile
- Social engineering

## Safe harbour

We will not pursue legal action over research that follows this policy, avoids privacy violations and data destruction, and gives us reasonable time to fix the issue before it is disclosed.
